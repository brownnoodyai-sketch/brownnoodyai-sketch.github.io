# NOODY.AI Public Website

This repository contains **only the customer-facing public website** for NOODY.AI.

Live site: https://brownnoodyai-sketch.github.io/

Public website scope:

- Island selection: Agatti, Kadmat, Kavaratti, Kalpeni.
- Product / Services selection.
- Public cards for customer discovery.
- Official NOODY WhatsApp enquiry links.

Private software, admin tools, Meta WhatsApp bot source, API/backend code, database, vendor/customer operational data, payment/refund/OTP logic and secrets are kept in the separate **private** NOODY.AI master repository.

Never commit access tokens, app secrets, webhook verify tokens, payment secrets, customer private data or vendor private documents to this public repository.
